# YMIND 中文使用说明

YMIND 是独立开发的中文思维导图编辑器，支持本机编辑、自动保存、多画布和多种文件导出。浏览器版和 Windows 桌面版使用同一套编辑界面，无需注册账号，也不需要外部服务密钥即可使用已实现的本地功能。

本项目没有修改 Xmind 安装文件或授权机制。Xmind 文件互操作依据公开文档结构实现；这里的功能及格式限制以本说明和实际验收为准，并不表示已经完成全部 Xmind 行为的一比一复制。AI 与多人在线协作目前待配置，不能作为可用功能使用。

## 1 运行方式

项目目录：

```text
C:\Users\shenzhendeyi\Desktop\REA\ymind
```

### 在本机浏览器中运行

已经安装项目依赖时，在 PowerShell 执行：

```powershell
Set-Location -LiteralPath 'C:\Users\shenzhendeyi\Desktop\REA\ymind'
npm run dev
```

保留这个终端窗口，在浏览器打开：

[http://127.0.0.1:5178](http://127.0.0.1:5178)

开发服务器只绑定本机地址。关闭服务器终端或按 `Ctrl+C` 后，浏览器刷新将无法继续加载程序；已经保存的本地数据仍保存在该浏览器中。重新运行相同命令并打开相同地址即可继续。

如果依赖尚未安装，先执行：

```powershell
Set-Location -LiteralPath 'C:\Users\shenzhendeyi\Desktop\REA\ymind'
npm ci
npm run dev
```

依赖安装和首次打包需要网络下载 npm/Electron 包。运行已构建的程序无需调用外部账户或 API。本项目使用 Node.js 的 TypeScript 测试支持；开发环境建议 Node.js 22.18 或以上，当前本机使用 Node.js 24.18。

### 运行 Windows 桌面界面

本机可直接双击项目中的 **启动YMIND.cmd**，或桌面上的 **YMIND** 快捷方式。启动器使用本机已安装的官方 Electron 加载本项目，不需要服务器、账号或模型接口。

在已安装依赖的项目目录中执行：

```powershell
npm run build
npm run desktop
```

`build` 生成界面资源，`desktop` 打开 Windows 桌面窗口。源代码更新后，应重新运行 `npm run build`，再打开桌面界面。

### 生成独立 Windows 程序

```powershell
npm run dist:win
```

打包完成后的目标文件为：

```text
C:\Users\shenzhendeyi\Desktop\REA\ymind\release\YMIND-1.0.0-Windows.exe
```

便携 EXE 已生成。但本机的 Device Guard 拦截了自定义 EXE 的启动；当前推荐上述启动器或浏览器版。官方 Electron 托管运行已完成实际桌面验收。其他电脑能否直接运行 EXE，取决于其应用执行策略。

## 2 五分钟完成第一张导图

1. 打开 YMIND，选中中心主题。
2. 双击主题，或按 `F2`，把标题改成你的项目名称；按 `Enter` 确定。
3. 选中中心主题后按 `Tab`，添加一个子主题，例如“目标”。
4. 选中“目标”并按 `Enter`，添加同级主题，例如“计划”。
5. 选中某个分支，继续按 `Tab` 创建下一层主题。
6. 在右侧设置区选择主题颜色、字号、形状和布局。
7. 等待保存状态显示“已保存”。通过保存功能还可以创建本地历史版本。
8. 导出一份 `.ymind` 文档，作为完整的可编辑备份。

第一次打开会显示示例文档。示例中的任务状态和内容只是普通可编辑数据，不表示已经执行了任何实际任务。

## 3 编辑主题

单击主题可以选中它。选中的主题是后续添加子主题、修改样式、设置备注和任务的操作对象。双击或 `F2` 进入标题编辑；输入中文时先正常完成输入法选词，再按 `Enter` 提交。

| 操作         | 快捷键或方式   | 说明                                           |
| ------------ | -------------- | ---------------------------------------------- |
| 编辑标题     | 双击 / `F2`    | `Enter` 提交，`Escape` 取消本次编辑            |
| 添加子主题   | `Tab`          | 添加到选中主题下，并展开父主题                 |
| 添加同级主题 | `Enter`        | 标题编辑时，此键用于提交；中心主题没有同级主题 |
| 删除选中分支 | `Delete`       | 同时删除其子主题，可撤销；中心主题不能删除     |
| 撤销         | `Ctrl+Z`       | 恢复当前编辑会话的前一次文档状态               |
| 重做         | `Ctrl+Shift+Z` | 恢复已撤销的修改                               |
| 关闭对话框   | `Escape`       | 退出当前弹窗，返回编辑界面                     |

快捷键在正文输入框、备注输入框或输入法组词过程中不会替代正常文字输入。

`Ctrl+S` 用于手动保存当前文档并创建本地历史快照。

折叠主题会隐藏后代显示，后代内容仍属于文档。展开可以重新看到它们。删除分支会实际删除内容；折叠和删除的用途不同。

移动分支时，为它选择新的父主题。中心主题不能移动到其他主题下，也不能把主题移动到自己或自己的后代中。

## 4 多画布

一个 YMIND 文档可以包含多个画布，每个画布有自己的中心主题、布局、配色、关系线和注释。通过画布列表切换当前画布；添加、重命名和删除画布通过相应的画布操作完成。

可以把同一项目的“总览”“实施计划”“资料整理”分别放在不同画布中。画布切换不会删除其他画布的内容。文档至少保留一个画布。

文档导出和图像导出的范围有所不同：`.ymind`、`.xmind`、Markdown、OPML 和 Office 文档处理整个文档；SVG、PNG 和 PDF 输出当前画布。

## 5 布局和样式

当前支持以下十三种布局：

| 布局           | 适用场景                                   |
| -------------- | ------------------------------------------ |
| 思维导图       | 中心主题两侧展开，一般的构思与整理         |
| 向右逻辑图     | 从左向右读流程或分层分类                   |
| 向左逻辑图     | 从右向左展开分支                           |
| 组织结构图     | 上下级关系和组织层级                       |
| 树状图         | 目录、分类和递进层级                       |
| 时间轴         | 按顺序展示阶段；节点顺序本身不表示真实日期 |
| 鱼骨图         | 原因分析、问题分解                         |
| 放射布局       | 围绕中心主题分散展示分支                   |
| 大括号图       | 用括号组织分类与分解关系                   |
| 树形表格       | 以表格单元格展示主题层级                   |
| 矩阵           | 将一层分支与子主题分成矩阵区域             |
| 向上组织结构图 | 从下向上展示层级关系                       |
| 纵向时间轴     | 沿纵向展示阶段，真实日期仍由任务字段记录   |

主题配色包括经典、海洋、森林、日落、紫色、单色和深色。画布配色提供整体分支颜色；主题自身的颜色和文字设置用于局部调整。

选中主题后可修改颜色、文字颜色、字号、粗体、斜体和形状。形状包括圆角矩形、矩形、椭圆、下划线和菱形。切换布局会重新计算显示位置，不改变主题父子关系。

画布可以缩放和移动。内容较多时先使用适应画布的显示功能，再调整缩放比例。大纲和搜索用于定位较远或较深的主题。

主题自动编号可按画布设置为无编号、数字编号、层级编号或罗马数字。编号属于显示设置，编辑主题时看到的仍是原始标题，切换编号方案不会把数字写入标题。

需要在一个主题中混合粗体、斜体和下划线时，使用富文本编辑入口。富文本由多个文字段组成，保存后的纯文本标题仍用于搜索和普通大纲导出。Word 导出会保留这些文字段的粗体、斜体和下划线；其他文字导出主要保留普通标题。

富文本编辑器支持格式按钮，也可输入 `**粗体**`、`*斜体*`、`__下划线__` 源文本。保存后会转换为相应的文字段，普通标题中不保留这些格式标记。

悬浮主题是一棵独立的主题树，不自动连接到中心主题。可以在画布中移动它，并为它添加子主题。完整 YMIND 文档保留其位置；Xmind 交换使用公开的 detached 主题与 position 坐标。

## 6 关系线 边界和概要

关系线用于连接两个主题，表达依赖、影响、引用等与父子层级不同的联系。创建时选择起点和终点，默认说明为“关联”；在右侧结构面板点击“编辑”可修改说明文字。

边界把一组主题放在同一区域内；概要给选定主题补充一个总括说明。它们属于注释，不会修改原来的主题层级。

按住 `Ctrl` 单击主题可以多选，选定范围后再添加边界或概要。在右侧结构设置中可以查看和移除已创建的关系线或范围注释。

完整 `.ymind` 文档可以保留这些内容。导出 `.xmind` 时，边界和概要只能表示**同一父主题下连续的兄弟主题**；跨父主题或不连续的范围会省略。需要完整保留任意范围的注释时，保存 `.ymind`，或导出当前画布的 SVG/PNG/PDF 作为展示材料。

## 7 备注 链接 图片和附件

备注适合保存较长说明。主题标题用于快速阅读，详细信息放入备注可以减少画布拥挤。搜索与大纲用于定位文档内容，备注仍保存在所属主题中。

链接可以记录资料网页地址。外部链接只有在明确点击后才会打开；网页仍需要正常的浏览器和网络条件。建议使用完整的 `https://` 地址。

图片以嵌入数据保存在文档中，适合插入示意图和小型参考图片。主要支持 PNG、JPEG、GIF 和 WebP 位图。附件以主题附属数据保存在完整 `.ymind` 文档中；附件不作为程序自动执行。

标记用于给主题补充星号、优先级或状态提示。在主题标记设置中选择常用符号，也可以输入以空格分隔的标记。Xmind 的标准标记标识与自定义 Emoji 不是同一种呈现方式，跨软件后不保证符号外观一致。

标签是主题上的短文字分类，与 Emoji 标记独立。每个主题最多 32 个标签，每个标签最多 256 个字符；完整 YMIND 和 Xmind 交换会保留标签文字。

`.xmind` 导出可以打包引用到的嵌入位图，每张最多 10 MB，总图片数据最多 20 MB。附件不会转换为 Xmind 附件。完整数据备份应选择 `.ymind`；图片很多时，先压缩图片尺寸再导入，以控制文档大小。

相同的嵌入图片在 Xmind 和 TextBundle 导出中复用一份资源。Xmind 导出最多 1021 个不同图片资源，连同三个 JSON 文件满足 1024 条目上限。

音频可以作为附件播放，也可以通过录音入口创建。只有主动点击开始录音后才会请求麦克风权限；停止后可预览，并嵌入为 WebM 音频附件。单次录音上限为 12 MB，可以取消而不保存。录音需要可用麦克风及浏览器或系统授权，本机硬件的实际收音尚未完成测试；状态切换与取消流程已验证。

## 8 数学公式

在主题公式设置中输入 TeX 数学表达式。这里的公式用于展示数学内容，不会运行本地代码，也不是电子表格公式计算器。

示例：

```tex
E = mc^2
```

```tex
\frac{a+b}{c}
```

```tex
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
```

公式保存在 `.ymind` 中。导图图像输出会绘制公式；Markdown、OPML、FreeMind、Xmind 和 Office 文字大纲的导出不保证保留公式结构。

## 9 任务 甘特和日历

主题可以设置为任务，并记录待办、进行中、已完成、开始日期、结束日期、负责人和进度。任务状态与主题层级是独立信息，一个分支可以同时包含任务和普通主题。

设置任务日期后，在任务或甘特视图中查看安排。甘特条基于任务真实日期绘制；没有日期的任务仍可以作为待办记录，但不会凭空获得排期。

日期建议使用 `YYYY-MM-DD`，例如 `2026-10-13`。日历导出也支持带明确时区的 ISO 时间，例如 `2026-10-13T10:00:00+08:00`。

导出 ICS 后，可由支持 `.ics` 的日历软件导入。规则如下：

- 只导出具有有效**开始日期**的任务；无日期或无效日期的任务跳过。
- 日期形式的任务导出为全天事件；结束日期按包含当天解释。例如 10 月 13 日至 14 日，是连续两天的全天任务。
- 带时区的开始和结束时间转换为 UTC；没有时区的纯时间字符串不作为有效日历开始时间。
- 结束日期无效、早于开始日期，或日期类型与开始日期不一致时，不导出这个结束字段。
- 没有任何可导出的任务时，界面会显示说明，不生成空日历文件。
- 导出文件不会自动写入你的在线日历，也不会邀请其他人参加。

## 10 保存 备份和历史版本

编辑后的当前文档自动保存在本机 IndexedDB。保存状态会提示正在保存、已保存或保存失败。遇到保存失败时，请立即导出 `.ymind` 备份，再检查浏览器存储空间和权限。

撤销与重做用于当前编辑会话。历史版本是单独的本地文档快照，保存操作会创建快照，当前保留最近 30 份。恢复某个历史版本前，建议先导出当前文档作为备份。

本地存储与浏览器配置文件、访问地址和桌面程序环境相关。以下场景请先保存 `.ymind` 文件：

- 换电脑、换浏览器、换浏览器用户配置文件。
- 清理浏览器网站数据或卸载桌面程序。
- 从浏览器版切换到桌面版，或反向切换。
- 在 `127.0.0.1` 与 `localhost`、不同端口之间切换。

浏览器和桌面版不会自动同步数据。通过导出和导入 `.ymind` 文件迁移最可靠。本地历史版本也不是团队协作文档历史。

## 11 导入格式与限制

导入前会检查文件结构和大小；损坏文件显示具体错误，不会用损坏内容替换当前文档。YMIND / JSON 完整备份上限为 64 MB，其他输入文件上限为 20 MB；文档最多 100 个画布、10000 个主题、128 层主题。编辑操作会按同一文档规则校验，超出容量时保留修改前的文档。

| 格式                         | 已实现的导入范围                                                                                            | 限制                                                                                                           |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `.ymind` / 本应用 `.json`    | 本应用文档，包含多画布和主题属性                                                                            | 只支持文档版本 1；不把任意 JSON 当作思维导图                                                                   |
| 现代 `.xmind`                | JSON 版 ZIP；画布、标题、主题树、标签、根级悬浮主题坐标、备注、链接、位图、标记、关系线、可表示的边界和概要 | 不支持旧版 XML、ZIP64、分卷、加密及受保护文件；不保证原版视觉一致；自有富文本/编号等限制见第 12 节             |
| `.md` / `.markdown` / `.txt` | Markdown 标题层级、缩进列表、引用备注和链接                                                                 | 一级标题可作为独立画布；不还原图片、复杂表格、关系线及原版任务属性                                             |
| `.opml`                      | 大纲层级、标题、文本备注和 URL                                                                              | 顶层 outline 作为画布；不还原复杂排版                                                                          |
| `.mm`                        | FreeMind 节点层级、文字标题、链接、折叠状态                                                                 | 主要支持文字节点；本应用导出的备注使用 `YMIND_NOTE` 属性；不保证其他软件的 HTML 富文本备注或自定义扩展完整转换 |

Xmind ZIP 解压总量最多 64 MB，单条文件最多 20 MB，资源条目最多 1024 个；文件会检查路径、大小和 CRC。XML 文件不接受 DTD 或自定义实体。未知的作者元数据、私有扩展、未引用的资源和其他无明确映射的字段不会复制到 YMIND 文档。

密码或受保护文件应先在原应用中通过正常功能导出非加密副本；YMIND 不解密，也不处理授权限制。

## 12 导出格式与限制

选择格式时，先确定需要继续编辑还是只需要分享。`.ymind` 用于完整备份；图像用于固定外观；大纲和 Office 文件用于后续文字或表格工作。

| 格式                   | 范围与内容                                                                                   | 主要限制                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| YMIND `.ymind`         | 整个文档，可重新编辑；主题、任务、公式、图片、附件、样式、注释、标签、富文本、悬浮位置和编号 | 主备份格式；序列化后的文件最多 64 MB                                                                   |
| Xmind `.xmind`         | 整个文档；真实现代 Xmind ZIP，包含资源、标签及悬浮主题坐标                                   | 原版视觉可能不同；任务/公式/附件不转换；大括号/树表回退，自有编号/富文本仅保证 YMIND 再导入恢复        |
| Markdown `.md`         | 整个文档，多画布、标题、层级列表、文本备注和链接                                             | 不保存布局、图片、任务、关系线、局部富文本或注释                                                       |
| TextBundle `.textpack` | 真正的 ZIP，包含 Markdown 与嵌入位图，使用 assets/ 相对图片引用                              | 只支持导出；不保存附件、布局、任务、关系线、编号或局部富文本；详见下方限制                             |
| OPML `.opml`           | 整个文档，主题层级、备注和链接                                                               | 不保存布局、图片、任务、关系线或注释                                                                   |
| FreeMind `.mm`         | 主题层级、备注、链接和折叠状态                                                               | 多画布合并在一个文档根节点下；画布名不一定保留；不保证富文本转换                                       |
| SVG `.svg`             | 当前画布，矢量导图                                                                           | 折叠主题按当前可见状态输出；图片作为嵌入位图；不能当作 YMIND 可编辑文档                                |
| PNG `.png`             | 当前画布，无损位图图像                                                                       | 受图像尺寸上限约束；大型导图优先选 SVG                                                                 |
| JPEG `.jpg`            | 当前画布，有损位图图像                                                                       | 背景为白色，有损压缩可能影响细小文字；与 PNG 共用像素限制                                              |
| PDF `.pdf`             | 当前画布，A4 单页展示                                                                        | 图像缩放适应一页，较大导图的文字可能较小；这是展示文件，不是可编辑导图或可搜索文字 PDF                 |
| Word `.docx`           | 整个文档，标题层级、局部富文本样式、备注、链接和任务说明                                     | 真实 Word OOXML；文字大纲，图片与附件不嵌入，不保存悬浮位置和导图编号                                  |
| Excel `.xlsx`          | 每个画布一个工作表；层级、主题、完整路径、备注、链接、任务状态、起止日期、负责人和进度       | 真正的 Excel OOXML 文件；不复制节点位置和关系线；同名或不合法的工作表名会调整                          |
| PowerPoint `.pptx`     | 每个画布的一层分支生成一页；分支标题、后代大纲、备注                                         | 真正的 PowerPoint OOXML 文件；最多 50 页，单个分支正文最多 22 行；超过上限会说明需要拆分，不会默默截断 |
| 任务日历 `.ics`        | 有有效开始日期的任务                                                                         | 日期规则见第 9 节；不直接接入日历账户                                                                  |

PNG、JPEG 和 PDF 需要在浏览器或 YMIND 桌面窗口内生成。当前图像画布单边最多 16384 像素、总量最多 4800 万像素；超过限制时降低导出倍率、拆分画布或使用 SVG。导图内容不会为了通过限制而偷偷截断。

Office 导出只在选择相应格式时加载对应模块；输出内容来自当前 YMIND 文档，不调用 Xmind 导出接口或会员功能。

TextBundle 压缩包导出为正式 `.textpack` ZIP，包含 `info.json`、`text.md` 和 `assets/` 图片目录。Markdown 中的图片使用相对路径引用实际资源，不会只输出文件名占位。只能打包已嵌入的 PNG/JPEG/GIF/WebP 位图，不下载远程图片，单张最多 10 MB、图片总量最多 20 MB、压缩包最多 20 MB、解压内容最多 64 MB。这个版本只导出 TextBundle，不直接导入 `.textpack` 或 `.textbundle` 文件夹；需要继续完整编辑时仍使用 `.ymind`。

现代 Xmind 的普通布局、标签和根级悬浮主题采用公开结构映射。公开 SDK 未给出大括号图、树形表格的专有现代结构类，因此导出分别使用逻辑图、矩阵列结构作为可读回退。原始布局选择、主题自动编号和局部富文本保存在 `local.ymind.editor` 自有扩展中；YMIND 再导入可恢复这些设置，其他软件不一定显示它们。未知第三方扩展不会复制。缺少坐标的悬浮主题会放在默认位置；嵌套在非根主题下的 detached 主题暂不支持，导入会说明原因。

## 13 专注和演示

专注模式用于减少侧栏等编辑控件的干扰，便于阅读当前导图。退出后可以继续编辑。

演示模式根据当前文档内容进行展示。它是本地展示功能，不会创建直播、在线会议或共享链接。需要分享给其他人时，可以导出 PDF、PNG、SVG 或 PowerPoint 文件。

本地演示以当前画布的一层分支分页。用右方向键或空格向后，左方向键向前，`Escape` 退出。

## 14 AI 与云协作

当前版本没有接入 AI 服务，也没有建立多人实时协作后台。相关入口显示待配置状态，不会使用假的 AI 结果或假的同步成功提示。

编辑、保存、备份、导入、导出和本地演示无需 API Key。将来接入 AI 或云协作，需要单独指定服务商、账户、网络和数据存储方案；本版本没有进行这些配置。

## 15 常见问题

### 浏览器页面打不开

确认 `npm run dev` 仍在运行，并打开 `http://127.0.0.1:5178`。如果终端提示端口已占用，检查是否已有一个 YMIND 开发服务器；程序不会自动换到另一个端口。

### 桌面界面打不开或显示旧版本

先在项目目录运行 `npm run build`，构建成功后再运行 `npm run desktop`。桌面程序加载 `dist` 中的构建结果，不直接读取未构建的 TypeScript 源代码。

### 图片或附件多了以后无法导入

YMIND / JSON 完整备份输入上限为 64 MB，其他格式为 20 MB。图片和附件的嵌入数据会增加文档体积；减少图片分辨率、移除不需要的附件，或拆成多个文档后再保存。

### 旧 Xmind 文件提示缺少 content.json

当前只支持现代 JSON 格式。请在原应用中正常打开并另存为现代 `.xmind`，或者从原应用导出 Markdown/OPML 后再导入。

### Xmind 与 YMIND 的样式不同

互操作只转换有明确映射的字段。保留完整 YMIND 编辑数据请使用 `.ymind`；需要固定展示外观请使用 SVG、PNG 或 PDF。

### 日历导出提示没有任务

仅有任务状态、负责人或进度还不足以生成事件。为任务设置有效开始日期后再导出；`2026-02-30` 之类不存在的日期无效。

### PowerPoint 提示分支太长

把较长分支拆成多个一层分支，或导出 Word/Excel 大纲。超过 50 页或单页正文容量时，导出会停止并显示具体原因。

### 自动保存失败

先导出 `.ymind`，检查浏览器是否处于限制存储的模式、网站存储是否可用，以及本机空间是否充足。不同地址、端口和浏览器配置不会自动共用文档。

### 清理网站数据后找不到历史文档

自动保存和历史都在本机存储中。通过之前导出的 `.ymind` 文件恢复；本版本没有云端恢复服务。

## 17 公开格式资料

现代 Xmind 格式映射参考官方开源 SDK 中的公开契约：

- [Xmind SDK 文档模型](https://github.com/xmindltd/xmind-sdk-js/blob/master/src/common/model.ts)：主题、备注、图片、标记、关系线、边界和概要的结构。
- [Xmind SDK ZIP 打包方式](https://github.com/xmindltd/xmind-sdk-js/blob/master/src/utils/zipper.ts)：content、metadata、manifest 和资源文件。

- [Xmind 官方现代序列化](https://github.com/xmindltd/xmind-generator/blob/main/src/internal/serializer.ts)：标签数组与资源引用。
- [TextBundle 规范](https://textbundle.org/spec/)：压缩包 `.textpack`、文件夹 `.textbundle`、元数据及相对图片资源路径。

这些资料用于文件互操作。YMIND 的界面、程序逻辑和输出内容由本项目独立实现。

## 18 本机保存、功能覆盖与验收

桌面数据位于 `%APPDATA%\YMIND`，使用应用内 IndexedDB；浏览器按地址、端口和配置分别存储。每次写入在同一个事务中核对版本标识，其他窗口已更新时会显示保存失败提示，保留本窗口内存内容供导出。此时先导出备份，再重开；不要清除存储。读取到损坏记录时会暂停写入，保留原始记录。

撤销最多保留 80 个快照，并按约 64MB 的内容预算裁剪，至少保留最近一个快照；大文档的可撤销步数可能减少。Ctrl+S 的本机历史保留最近 30 个版本。图片可从样式面板移除；附件可以下载、替换或移除。导图显示和导出只使用嵌入的位图，遇到外部图片地址会提示重新插入，不自动访问该地址。
